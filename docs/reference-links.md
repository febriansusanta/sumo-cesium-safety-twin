# Reference Links

Useful external links saved for future project work.

| Name | Link | Notes |
| --- | --- | --- |
| NLSC map query page | https://maps.nlsc.gov.tw/MbIndex_qryPage.action?fun=8 | Reference map page provided by the user. NLSC Taiwan remains an optional Cesium basemap; CARTO Dark is the global default. |
| SUMO netconvert options | https://sumo.dlr.de/docs/netconvert.html | Official reference for network conversion options, including `--lefthand` for left-hand traffic networks. |
| SUMO left-hand FAQ | https://sumo.dlr.de/docs/FAQ.html | Official FAQ confirmation that left-hand networks should be built with `--lefthand`. |
| Mapbox Static Tiles API | https://docs.mapbox.com/api/maps/static-tiles/ | Used by the optional `Mapbox 3D Buildings` basemap imagery layer. Requires `VITE_MAPBOX_TOKEN`. |
| Mapbox Vector Tiles API | https://docs.mapbox.com/api/maps/vector-tiles/ | Used to request Mapbox Streets vector tiles from the browser. |
| Mapbox Streets v8 tileset | https://docs.mapbox.com/data/tilesets/reference/mapbox-streets-v8/ | Provides the `building` layer rendered as Cesium extruded polygons. |
